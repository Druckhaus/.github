## Was wir machen

Wir verbinden persönliche IT-Betreuung mit individueller Softwareentwicklung –
vor Ort im Ruhrgebiet und remote.

| Bereich | Leistungen |
| --- | --- |
| **IT-Support** | Arbeitsplätze, Hardware, Windows, macOS und Microsoft 365 |
| **Netzwerk & WLAN** | Analyse bestehender Netzwerke sowie Konfiguration von Routern, Switches und Access Points |
| **Web & Software** | Websites, Onlineshops, Web-Anwendungen, APIs und Automatisierung |
| **Hosting & Infrastruktur** | Domains, E-Mail, SSL, Hosting, VPS und Migrationen |
| **Digitale Präsenz** | Einrichtung und technische Pflege von Google-Unternehmensprofilen |

## Technischer Fokus

- **Frontend:** React, Next.js, TypeScript und Tailwind CSS
- **Product Engineering:** individuelle Web-Anwendungen, E-Commerce,
  Konfigurationslogik sowie Datei- und PDF-Workflows
- **Delivery:** GitHub Actions, automatisierte Tests, Semantic Release, Coolify
  und Nixpacks
- **Operations:** Linux/VPS, Domains, E-Mail, Windows, macOS, Microsoft 365 und
  Netzwerk-Infrastruktur

## Wie wir arbeiten

- Individuelle Entwicklung, wenn Standardlösungen nicht ausreichen
- Klare Staging- und Review-Prozesse vor dem produktiven Release
- Automatisierte Qualitätsprüfungen und reproduzierbare Deployments
- Projektbasierte Umsetzung oder kontinuierliche technische Betreuung
- Direkter Support auf Deutsch und Englisch

### Reliable IT. Purpose-built digital solutions.

DevHaus develops and operates digital solutions and supports medical practices
and small businesses across the Ruhr region with IT, web and hosting services —
on site and remotely.

Our technical focus includes React, Next.js, TypeScript, custom web
applications, e-commerce, APIs, automated file and PDF workflows, GitHub
Actions, automated testing, Semantic Release, Coolify, Nixpacks and Linux/VPS
operations.

We deliver both individual projects and ongoing technical support in German and
English. Most product and customer repositories are private; this profile only
shows references approved for public presentation.
